# Nobus Space — рабочие каталоги и резервные версии

Актуально 6 октября 2026. Канон публикации — GitHub main, исполняемая ревизия — [CURRENT](CURRENT-STATUS.md). Копия рабочего дерева, Git-история, комплект для возврата и резервная копия БД выполняют разные роли.

| `.runtime/voice-models` | Модели; не тестовый кэш |

Ровно два актуальных **кодовых** комплекта находятся в `.runtime/rollback`. Каждый содержит source ZIP, backup config, XML трёх задач, launcher и manifest; запуск старого пакета отдельно не разрешается его наличием. Прежние signed journal/config snapshots хранятся как доказательства операций; это не материал для подмены нынешней history или запуска старой конфигурации.

Политика копий четырёх БД остаётся **7 daily / 4 weekly** по точному Backup config. Они не входят в лимит двух резервных кодовых версий. Recovery history, подтверждения доставок, пользовательские результаты и данные не удаляются при уборке.

Доступные лишние test clones/caches удаляются только по exact path/commit/hash после проверки восстановимости. Неподтверждённые source exports, чужой/уникальный WIP, зарегистрированные shared worktrees и недоступные Windows каталоги сохраняются с причиной. [Фактическая квитанция и остаток](REPOSITORY-MAINTENANCE.md). ACL, владелец каталогов и глобальный safe.directory не меняются. Исторические Git refs/tags/приёмки сохраняют объекты и доказательства, а не дополнительные runnable backup-копии.
