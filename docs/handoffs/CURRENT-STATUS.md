Изменения этой публикации поверх `207778a` относятся только к документации.

У владельца остаются плитки и Mini App. Артуры работают текстовыми командами по [инструкции](../CODEX-AGENT-COMMANDS.md). В данной версии нет `/codex status <UUID>`, отдельного project allowlist для каждого Артура или общей машиночитаемой корреляции каждого вложения. Это ограничения установленной реализации, а не реализованные обещания.

Новый локальный source-кандидат `1b6af61` для отдельного канала Артура не установлен и сюда не включён; его незавершённая работа сохранена отдельно. Публикация `207778a` не активирует этот канал и не передаёт агентам сессию владельца.
