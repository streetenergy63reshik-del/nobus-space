Продуктовый `NetworkCommandRunner` допускает `pip install` только после
точного owner approval, для двух имён requirements-файлов, с фиксированным
индексом PyPI, `--require-hashes` и `--only-binary=:all:`. Это снижает
доступность перечисленных сценариев, но не исправляет `pip 25.0.1`.
До обновления pip до версии не ниже 26.2 новые package-install эффекты
не считать проверенными для M2-DESKTOP. Массового обновления зависимостей
не требуется; установка/замена pip пока не выполнялась при действующем
запрете на удаление файлов.

Дополнение 25.09 для code checkpoint `fe333c6`: diff от `fa6f1f0`
затрагивает только четыре исполняемых Python-файла, тесты и документы;
зависимости/credentials не менялись. Адресный `rg -l` по шаблонам
OpenAI/GitHub/AWS/PEM ключей в этих четырёх файлах не нашёл совпадений.
Это ограниченный статический поиск, не полноценный secret scan или CVE-аудит.
Новые данные не превращают прежний эвристический отчёт в release verdict;
живые доверенные границы R01/R02 и D01–D17 остаются открытыми.
