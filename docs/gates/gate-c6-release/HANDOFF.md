## Оставшиеся пользовательские сценарии

Подтверждены три настоящих результата с TXT. После включения исправления остаются:

1. Текстовая просьба подготовить промпт с материалом, содержащим действия, и корректным уточнением при условии в ответе.
2. Голосовая просьба подготовить промпт: прочитать распознавание, подтвердить, получить результат и TXT.
3. Вторая последовательная задача Mini App: дождаться результата, повторно открыть и скачать связанный TXT без подмены первой задачей.

Это реальные действия через интерфейс владельца. Внутренний вызов Core или результат модели не доказывает просмотр распознавания либо скачивание файла. Доступные средства управления интерфейсом сейчас не запускаются из-за проверки доверенного RPC-пакета. Последняя просьба владельца отложить личное тестирование сохраняется; дальнейшее действие требует его участия или явного изменения согласованных критериев.
