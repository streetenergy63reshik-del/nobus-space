# ADR-0001. Nobus Space автоматизирует функцию менеджера маркетплейса

**Статус решения:** ACCEPTED

**Дата:** 2026-07-20

## Контекст

PROстранство требуется не набор разрозненных помощников, а управляемый контур, который постепенно выполняет повторяемую работу менеджера маркетплейса и оставляет человеку решения с существенным риском.

## Решение

Развивать Nobus Space как внутреннюю операционную платформу: постановка, исполнение, проверка, согласование и аудит задач. Северная звезда — снять типовую операционную нагрузку менеджера, но не обещать полную автономию там, где нет безопасного adapter, доказательств или L4.

Первый продуктовый срез — Telegram-оркестратор для разработки самой платформы. Доменные функции маркетплейсов подключаются после стабильного Core отдельными adapters.

## Последствия

Положительные:

- единый state/audit вместо чатов и несвязанных скриптов;
- качество и права являются частью продукта;
- можно подключать новые роли без смены Core.

Отрицательные:

- ценность появляется поэтапно, а не после одного «универсального агента»;
- каждое внешнее действие требует контракта, тестов и операционного владельца;
- человек остаётся обязательным L4 для внешней записи и высокого риска.

## Не следует из решения

- готовность всех функций менеджера в MVP-1;
- право агентов менять цены, рекламу, публикации или доступы;
- коммерческий SaaS или многопользовательский режим.

## Проверка решения

Решение подтверждается, если Telegram MVP выполняет хотя бы один сквозной тип задачи с tenant binding, L1/L2/L3 и контролируемым L4, а следующий доменный adapter подключается без переписывания Core.
